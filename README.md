# Resume AI Tailor

AI-powered web application for resume tailoring with ATS optimization and
hallucination control.

**Bachelor Thesis Project — Riga Nordic University, Programme 42484 Information Systems**

## Features
- Upload your resume (PDF or DOCX)
- Paste any job description
- Choose between 4 prompt engineering strategies
- Get ATS keyword coverage, hallucination rate, tailoring score, and readability

## Live demo
https://kama278.github.io/work/

## Tech stack
- HTML5, CSS3, Vanilla JavaScript (ES6+)
- PDF.js, mammoth.js (file parsing)
- Grok API by xAI (LLM)
- GitHub Pages (hosting)
- localStorage (data storage)
